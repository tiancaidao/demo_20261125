## What this demonstrates

Save: discover and reuse maintained Save confirmation and Undo behavior while preserving the selected image, title and resolved URL.

Logging: follow a fictional enterprise policy by replacing raw model-response and exception logging with a fixed diagnostic event, while preserving fallback behavior.

## Evidence and limits

These are prepared implementation comparisons, not an experiment proving AGENTS.md alone caused the change. Original code authorship is not established. Builds, analysis and tests have not been run. Included regression examples remain unverified. Human review and normal validation are required before production use.

Only selected code changes, instructions and review notes are published here. No private repository history, full application, credentials or production data are included.
